# 后台任务模块说明

当前阶段**未确定**任务队列框架（候选：Celery / ARQ / asyncio 原生任务），
故 `app/tasks/` 仅保留模块骨架，不引入具体实现依赖。

## 规划

- **定时任务**：缓存预热、数据同步、报表生成等
- **异步任务**：文档切分索引、模型调用等耗时操作（将由 AI / RAG 服务触发）

## 决策点（后续确认）

1. 框架选型：Celery（生态成熟） vs ARQ（轻量、纯 asyncio） vs 原生 asyncio 任务
2. Broker：默认基于本项目已有的 Redis
3. 任务如何由业务模块调用（Service 层解耦，避免 API 直接依赖任务队列）
